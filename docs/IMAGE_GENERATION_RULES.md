# Image Generation Rules — 每次生成前必读

> 适用于所有角色/敌人/动作帧的图片生成：Seedream `image_to_image`、`multi_image_fusion`、基准图生成、火焰形态变体、单帧重生成。
> 每次调用图片生成前先读完本文件；生成后按 §7 的接触表检查逐项验收。
> 素材的生成流程、提示词前缀、导入命令仍以 `docs/ASSET_PIPELINE.md` 为准；本文件是生成前/生成后的质量门禁。

## 0. 一句话目标

同一个角色在每一帧里保持**相同的身体尺寸、头身比、镜头距离、脚底基线**；**近侧肢体在身体前方、远侧肢体在后方**；**武器由同一只手以可信的握姿持握**；**所有部件正确遮挡、互不穿透**。任何一项失败，重生成该帧，不用拉伸、擦除、镜像或局部修补来掩盖。

## 1. 生成前检查（Pre-flight）

在写 prompt 或调用工具前，确认这些信息已经明确：

- [ ] 使用哪张 canonical 图 / approved base 作为唯一或主要参考。
- [ ] 角色的**持武器手**（左手/右手）和**近侧/远侧**（靠近镜头的一侧）。
- [ ] 该动作的握法：单手 / 双手、正握 / 反握、握在斧柄的哪个位置。
- [ ] 该动作的身体朝向：右向 3/4 侧视；运行时只翻转朝左，不生成左向帧。
- [ ] 画布、pivot、身体高度、武器比例、镜头距离、脚底位置（沿用 approved base）。
- [ ] 该帧的动作描述只改变姿势；服装、武器设计、配色、镜头、比例不变。
- [ ] 全身和完整武器在画面内；透明背景；无影子、文字、边框、场景。

**完成标准**：以上每一项都能在 prompt 或参考资料中落到具体描述；没有“看起来差不多”的模糊项。

## 2. 身体部件前后位置（Layering）

按“近侧在前、远侧在后”检查每一组遮挡：

- **近侧手臂**在躯干前方；**远侧手臂**在躯干后方。不要让远侧手臂绕过躯干出现在胸前。
- **近侧腿**在远侧腿前方；膝盖、脚踝、靴子的遮挡顺序保持一致。
- 肩甲、护腕、腰带、腰布、披风/飘带跟随近/远侧关系；远侧饰物不盖住近侧身体。
- 头发、头带、耳朵、脸部：近侧头发在肩前，远侧头发在肩后；远侧飘带不穿过脸或脖子。
- 武器与身体：握武器的手臂在前，武器柄在手的握持范围内；武器可以横过躯干前方，但不能从躯干内部穿出。

**失败信号**：远侧手臂出现在胸前；左右腿交换；肩膀/肘部反向；同一侧出现两只手/两条腿；躯干从手臂中间穿出；手在斧柄后方但手指画在斧柄前方。

**完成标准**：在 100% 缩放下，近/远侧的肩、肘、腰、膝、踝遮挡关系与 approved base 一致；没有部件互换前后。

## 3. 握武器的手臂与姿势（Weapon hand & grip）

先确定“哪只手是持武器手”，再检查握姿在所有帧中一致：

- 手指**包住斧柄/刀柄**，不是贴在斧柄表面或悬空；拇指位置可信，指节数量正常。
- 手掌与斧柄之间没有空隙、没有互相穿透；斧柄不从手掌中间穿出。
- 单手动作：另一只手的位置明确（自然下垂、平衡、护身），不要也去握武器。
- 双手动作：两只手都在斧柄上，间距合理；近侧手在前，远侧手在后（或按动作明确指定）。
- 武器角度与刀锋方向一致；Warrior 的斧头是**单刃新月、刀锋在上方**，深色漩涡纹、金色配件、红色流苏保持不变。
- 武器不能穿过躯干、头、脖子、腿、头发或服装；斧头不能与肩甲/头发融在一起。
- 投掷/挥砍的释放帧：该松手时手是张开的，武器位置由动作决定；不要在同一帧里出现两把武器或“手还粘在飞出的斧头上”。

**失败信号**：左右手持武器互换；手指悬空/融合/多指；手掌穿进斧柄；斧刃穿过肩膀或大腿；斧头被裁切；斧头比例突然变大/变小；同一帧出现两把斧头。

**完成标准**：持武器手、握点、握法、武器角度在相邻帧之间连续；手与柄、武器与身体的接触关系可信。

## 4. 不穿模（No interpenetration）

逐对检查，而不是只看整体轮廓：

- 近侧手臂 / 躯干；远侧手臂 / 躯干
- 手 / 斧柄；手指 / 斧柄
- 武器 / 躯干、头、脖子、腿、头发
- 双腿 / 腰布、裤腿、靴子
- 肩甲 / 上臂；护腕 / 前臂
- 头发 / 肩、背、武器飘带
- 服装边缘 / 身体；腰带 / 腰布

要求：

- 每个部件在交叠处有明确的“谁在前、谁在后”，轮廓线连续，不出现互相切入的硬边。
- 没有多余肢体、缺肢、融合手指、漂浮碎片、从衣服里穿出的皮肤、被衣服吞掉的肢体。
- 布料/护甲边缘贴合身体轮廓，不出现身体从护甲中间穿出。
- 武器和手之间没有“半截手指”或“半截斧柄”。

**完成标准**：在 100% 和 200% 缩放下检查所有交叠处；没有互穿、破洞、融合或漂浮部件。

## 5. 不改变角色大小（Size / proportion lock）

同一角色的所有帧必须共享：

- **身体高度**（从脚底到头顶）；头的大小；肩宽；四肢粗细；脚/靴子尺寸。
- **武器尺寸和比例**；斧头长度、斧刃大小、斧柄粗细。
- **镜头距离、透视角度、脚底基线**。
- **画布缩放**：不要因为动作变大/变小而 zoom、拉伸、压扁或改变透视。

做法：

- 以 approved base 为比例基准；动作帧只改变姿势，不改变角色比例。
- 武器可以伸出身体轮廓，但必须完整在画布内（或按已批准基准的裁切规则），比例不变。
- 接触表上用脚底基线和头顶位置对比 base；发现漂移就重生成该帧。
- **不要**用 `smoothscale`/自由变换/擦除来“修”比例错误的帧；这会把错误带进游戏。

**完成标准**：接触表中所有帧的头顶、脚底、身体高度、武器长度与 base 对齐；没有逐帧自动缩放。

## 6. 追加到每次 prompt 的固定块（英文）

在 `docs/ASSET_PIPELINE.md` 的角色前缀之后追加：

```text
Preserve the exact same character identity, body height, head size, shoulder width,
limb proportions, weapon size, camera distance, foot position and lighting as the reference.
Right-facing three-quarter side view, full body and the entire weapon inside the frame,
flat transparent background, no shadow, no text, no border, no scenery.

Correct near/far layering: the near arm and near leg are in front of the torso; the far arm
and far leg stay behind it. The weapon is held by the same hand with a believable grip around
the haft; fingers wrap the haft, and the hand/weapon do not intersect the torso, head, legs,
hair or clothing. No interpenetration, no merged or extra limbs, no floating parts, and no
duplicated weapon.

Only change the pose: <ACTION, FRAME N OF M>.
```

- 动作句里明确写“which hand holds the weapon”“one-handed/two-handed”“near arm/leg”。
- 投掷/释放帧明确写“hand releases the haft”“open palm”。
- 如果模型反复把远侧手画到前面，在动作句里再次点明 `near-side arm in front, far-side arm behind the torso`。

## 7. 生成后审批（Contact sheet gate）

对每个动作的接触表逐项检查：

- [ ] 近/远侧肢体没有互换；肩、肘、腰、膝、踝遮挡正确。
- [ ] 持武器手一致；握点、手指、拇指可信；没有悬空/融合/多指。
- [ ] 武器没有穿过身体、头发、服装；斧刃方向/单刃设计一致；没有第二把武器。
- [ ] 所有相邻部件没有互穿、破洞、融合、漂浮碎片。
- [ ] 身体高度、头身比、武器比例、镜头、脚底基线与 base 一致。
- [ ] 全身和完整武器在画面内；没有影子、文字、边框、背景。
- [ ] 与前后帧的姿势连续，没有突然换手/换脚/换武器角度。

**任一项失败 → 该帧标记为 rejected，重生成；不要用修图掩盖。**
只有整张接触表通过后才允许复制到 `assets/frames/<character>/<action>/`。

## 8. 常见失败与处理

| 现象 | 处理 |
|---|---|
| 远侧手臂跑到胸前 | 在 prompt 明确 near/far；重生成；不要用镜像掩盖 |
| 左右手互换持武器 | 在动作句明确“the right/left hand holds the haft”；重生成 |
| 手指悬空 / 手掌穿过斧柄 | 重生成；不要擦除或画手指修补 |
| 斧头穿过躯干/腿/头发 | 调整姿势或武器角度描述；重生成 |
| 斧头被裁切 | 加大画面边距/调整构图后重生成；不要裁身体 |
| 身体高度/头身比漂移 | 以 base 为参考重生成；不要 smoothscale |
| 武器比例变化 | 重生成；保持同一把武器尺寸 |
| 多余肢体/融合手指 | 重生成；不要局部擦除 |
| 衣服/护甲穿模 | 重生成；不要用色块覆盖 |

## 9. 与现有流程的关系

- 生成/导入/审批流程：`docs/ASSET_PIPELINE.md`。
- 角色尺寸参考：
  - Lina：256×256，pivot `(128,244)`，身体约 210px。
  - Warrior：384×384，pivot `(192,372)`，身体约 230px；单刃新月斧。
- 新角色/敌人：先确定 approved base 的画布、pivot、body height、武器尺寸，再批量生成。
- 本文件不改变 `Image/` 的只读规则；所有生成物只写入 `assets/generated/` 和 `assets/frames/`。

**快速验收口径**：近/远层正确、持武器手和握姿正确、无穿模、身体/武器尺寸不变。四项全过才算通过。
